# Conversion Copy

Trigger: create, rewrite, diagnose, or iteratively improve sales-oriented website copy.

Delegate:
- Buyer language/evidence → `buyer-research`
- Write money-page/landing/service copy → `seo-conversion-copywriting`
- Iterative improvement loop → `conversion-copy-loop`
- Structural teardown of external/reference copy → `copy-anatomy`

Hard rules:
- Follow `docs/standards/BRAND_AND_COPY.md` when positioning/public copy is touched.
- Evidence beats invented persuasion claims.
- Preserve SEO intent while improving clarity and conversion.
- Do not duplicate offer/funnel decisions owned by `offer-funnel-intelligence`.

Deliverable: finished copy or a precise copy decision grounded in evidence and route intent.
